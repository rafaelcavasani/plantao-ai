# Horários de funcionamento da Clínica Sorriso

- Segunda a sexta: das 08:00 às 18:00.
- Sábado: das 08:00 às 12:00.
- Domingo e feriados: fechado.

Em feriados prolongados o horário pode mudar; a recepção avisa pelo WhatsApp com antecedência.
O horário de almoço da recepção é das 12:00 às 13:00 nos dias úteis, mas os atendimentos agendados seguem normalmente.
